Keyboard Accessibility — All Test Cases

A reference page exercising every keyboard-trap detection case (WCAG 2.1.2). Inline (non-modal) cases are detected automatically when you scan this page. Modal cases open via their buttons — a scanner cannot click them, so open a modal first to scan it (or scan the individual fixtures). Each section is labeled with the outcome a11y-scout should produce.
